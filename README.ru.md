# Замер

[English version](README.md)

Замер — Android-приложение с открытым исходным кодом для лазерного дальномера HOTO Smart Laser Measure QWCJY001 (JY001). Оно подключается к дальномеру по Bluetooth и получает каждый замер. Из замеров приложение считает площадь, объём и высоту. Mi Home, аккаунт Xiaomi и интернет не нужны.

## Возможности

- Режимы «Длина», «Площадь», «Объём» и «Высота». Режим можно переключить кнопками или свайпом влево и вправо.
- Каждый замер заполняет следующую сторону. Чтобы переснять сторону, коснитесь её.
- В режиме «Высота» высота считается по двум замерам: по полу и наклонно до цели.
- У каждого режима свои стороны. Они сохраняются после перезапуска.
- Готовые результаты попадают в историю. Результату можно дать название, например «Пол на кухне», и потом найти его поиском.
- Все замеры попадают в журнал. Недавний замер можно подставить в любую сторону касанием.
- Метры или футы, от 1 до 3 знаков после запятой, светлая, тёмная или системная тема, цвета Material You.

## Требования

- Android 12 или новее с Bluetooth LE.
- Дальномер HOTO QWCJY001. Другие устройства HOTO и Xiaomi не проверялись.

## Привязка

1. Включите дальномер.
2. Откройте Замер и дайте разрешение на Bluetooth. Доступ к геолокации приложение не запрашивает.
3. Выберите дальномер в списке.

Дальномер помнит только одно привязанное приложение. Если привязать его к другому приложению, Замер покажет «Нужно спарить заново». Нажмите «Спарить», чтобы вернуть привязку. История при этом сохраняется.

## Сборка

Нужны JDK 17 и Android SDK (compile SDK 36).

```bash
./gradlew testDebugUnitTest assembleDebug
```

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Устройство кода и протокол описаны в [README.md](README.md) и [docs/PROTOCOL.md](docs/PROTOCOL.md).
